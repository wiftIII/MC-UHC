# Marvel UHC

Plugin Minecraft

# Informations

Minecraft version : 1.21.1
Java version : openjdk-22
IDE : IntelliJ 2022.4.1

Fait avec le template Paper

# How to build

Pour build il faut utiliser le Gradle Tasks->build->clean puis Tasks->build->build

Le plugin sera build et placé dans la hierarchie du projet (à gauche dans l'IDE). On peut le trouver dans build->libs->Marvel UHC-version.jars
